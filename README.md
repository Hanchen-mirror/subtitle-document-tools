# 字幕与文档整理工具

从个人字幕校对和演讲稿排版任务中整理出的几个小脚本。原任务中的固定路径、姓名、课题材料、原字幕和老师样例均已移除，例子全部为虚构内容。

**当前不是“视频一键生成文档”的完整应用。** 语音转文字、逐条判断错误以及整理发言逻辑仍需在这些脚本之外完成。本工具不调用模型服务，不需要 API 密钥。

## 安装

需要 Python 3.10 或更新版本：

```sh
python -m pip install -r requirements.txt
```

## 1. 按人工修改表校对 SRT

```sh
python correct_srt.py examples/input.srt examples/corrections.json output/corrected.srt
```

修改表使用字幕编号到新文字的 JSON 映射。脚本验证编号和时间戳，保留全部时间戳、顺序及未修改的字幕，并拒绝覆盖已有输出。它执行你给出的修改，不会自行判断听写是否正确。

## 2. 把整理好的文字排成演讲稿

```sh
python build_speeches.py examples/speech.json --output-dir output/speeches
```

输入 JSON 中每一项需要 `name`、`title`、`paragraphs`；可选 `appendix_title` 和 `appendix`。排版沿用原演讲稿脚本：A4 纵向、中文标题、正文缩进、页码及可选问答附录。脚本清空作者和最后修改者字段。

## 原项目与公开整理的区别

- 原字幕脚本包含针对两份具体课题字幕的改字表；公开版保留“编号对应修改、时间戳不变”的方式，把材料移到用户输入。
- 原演讲稿脚本读取固定 JSON；公开版改为命令行输入，并增加输出路径和覆盖检查。
- 曾做过按老师样例制作讨论记录的任务。原脚本依赖该样例的固定段落和私有正文；该模板专用流程尚未通用化，不随本次工具分发，避免读者误认为任意 Word 模板都能使用。

## 验证与限制

公开虚构示例可生成 SRT 和 DOCX。测试验证时间戳保持、未知编号与已有文件被拒绝，以及 DOCX 文字与作者字段；不等于各办公软件排版完全相同。字体缺失可能影响分页，正式文档仍应人工检查。

自行处理的音视频、讲稿与模板可能包含个人和项目资料，请放在已忽略的 `private/` 下。源码及虚构示例采用 MIT。
